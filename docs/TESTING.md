# 标准回归测试清单

每次完成一个功能后，先在本地执行自动化检查，再打开 Windows 浏览器做一次可见交互验收。自动化测试会优先拦截“按钮点下去后进入 404/422/错误状态”的问题。

## 必跑命令

```bash
.venv312/bin/python -m compileall -q app tests
.venv312/bin/python -m unittest discover -v
git diff --check
```

`tests/test_navigation_contract.py` 是全站导航契约测试，覆盖：

- 所有模板中的本地链接、表单 `action` 和流式接口是否能匹配已注册路由与 HTTP 方法；
- 所有状态变更表单是否包含 CSRF 防护；
- 删除/取消导入等危险操作是否存在确认步骤；
- Python 处理器中的重定向目标是否仍然存在；
- WeLink 主要按钮在演示数据下是否都返回 303，并回到正确的页面锚点，而不是 404/422。
- 工具首次发布的真实处理器测试会覆盖空更新说明、临时文件落盘、数据库记录和成功 303 跳转；`release_notes` 不能因为页面留空而触发 422。
- 工具发布/修改页和案例编辑器测试需要确认富文本/Markdown 切换、标题/粗体/GFM 表格/链接/分隔线/代码块实时预览、富文本内容提交前同步回 `details`/`body`，以及 `773 × 837` 窄屏不出现横向溢出。还要检查共享 `editor-media.js` 的图片类型/2 MB 校验、剪贴板图片粘贴、图片 25%/50%/75%/原始尺寸转换与 `{width=...}` Markdown 往返。

## 浏览器验收

启动 `uvicorn app.main:app --port 8001` 后，用 Windows Chrome 或 Edge 检查：

1. 登录、退出和匿名访问 `/` 是否分别进入正确页面；
2. 每个主导航入口、返回按钮、分页、筛选和详情链接是否打开预期页面；
3. 每个新增/保存/启用/暂停/删除按钮是否显示处理中状态，并出现成功或可理解的错误提示；
4. 危险操作是否先确认，取消确认后业务数据不变；
5. WeLink 的“巡检管理”入口是否能统一打开当前分组、演示/生产切换和分组设置；报告生成、消息源批量操作、消息源/接收方编辑和删除、审计台账跳转是否正常；保存消息源或接收方修改后应回到当前分组对应的来源/接收方列表，不得出现 404/原始 JSON 错误页；
6. 两个智能问答入口的普通 Enter 换行、Ctrl/⌘+Enter 发送、发送/停止、流式 Markdown、历史对话和重命名是否正常；
7. 日志上传、报告导出/下载、案例发布、工具首次发布/版本发布和需求评审等关键链路是否无错误跳转；工具首次发布时可留空“本版本更新说明”，但必须选择工具文件；
8. 工具详情正文的 Markdown 标题、粗体、列表、表格、链接、分隔线、代码块、图片均能安全渲染，正文行距约为 1.5 倍；工具编辑页点击“取消编辑”返回对应详情页且不提交修改，图片按钮和剪贴板均可插入 PNG/JPG/GIF/WebP，选中图片后应出现右下角拖拽手柄；拖动可直接改变宽度，25%/50%/75% 以原图宽度计算且不放大，原始会恢复自然尺寸，超过 2 MB 时给出可理解提示。案例正文编辑器逐项执行同样的图片/表格/链接/分隔线/代码块验收；表格应能看到容器边框、表头底色、单元格分隔线和斑马行，浅色/深色主题均可读，超宽表格可在容器内横向滚动；管理员能看到删除按钮，普通用户看不到且直接调用删除接口返回 403；
9. 需求提交人分别在“待评审”和“已采纳/规划中/已实现”状态修改需求，确认版本历史、旧评审意见仍在，当前状态自动回到“待评审”，并确认其他账号不能打开或提交修改表单；
10. 在 `1011 × 837` 和 `773 × 837` 视口下检查无横向溢出，并查看浏览器控制台没有错误或警告。
11. IDaaS 灰度验收使用 `AUTH_PROVIDER=hybrid`：确认登录页出现 OAuth2 入口，授权跳转使用 `response_type=code` + PKCE 且地址不含密钥和 `nonce`；普通/审核/管理员测试账号分别完成 Token 换取、UserInfo 身份映射、幂等登录、角色限制和退出。再用错误 state、过期授权码、Token 失败、UserInfo 不可达和缺少稳定用户 ID 验证统一回登录页，不显示敏感错误。不得以 ID Token、OIDC Discovery、JWKS 或 issuer/audience 校验作为验收条件。
12. WeLink P0 验收：用两个普通账号分别创建个人空间和共享分组，确认来源/接收方/运行/报告/问答只显示当前分组；问答历史切换分组后不可见，跨分组重命名返回 404；非成员直接提交问题状态或行动项 ID 返回 404/403。开启 `WELINK_CONNECTOR_ENABLED=1` 后配对设备，验证一次性令牌、心跳、任务租约、幂等领取、结果回写和撤销；运行 `.venv312/bin/python -m app.welink_scheduler` 两次，确认同一分钟只产生一个定时任务。真实 CLI 只能在公司授权测试群执行。
13. OAuth2 生产验收：只配置 `OAUTH_CLIENT_ID`/`OAUTH_CLIENT_SECRET` 与生产 `APP_BASE_URL`，确认 `/auth/login` 跳转 UniPortal 固定授权路径且 URL 不含 Secret；W3 完成后必须回调 `/authorize` 而不是 404。配置 `AUTH_PROVIDER=oauth2` 后登录页只能看到华为工号入口；使用 `j00983211` 和 `j00456121` 分别登录，两者都应成为最高管理员，普通账号不得看到 `/admin` 导航或访问应用管理。管理员调整贡献者/审核者权限后重新登录验证权限；应用管理中的审计应记录成功/失败登录、退出、权限修改和关键写操作，但不得出现密码、Client Secret、access token 或表单正文。

验收过程中不要点击真实生产桥接、真实 WeLink 群发送或删除重要业务数据；生产验收应使用已授权的测试群和可回滚数据。

## 新增功能的最低要求

新增一个按钮或跳转时，必须同时补充：

1. 对应的注册路由和成功/失败重定向；
2. 至少一个路由级测试，验证状态码、目标路径和数据变化；
3. 模板导航契约能识别的本地链接/表单；
4. 危险操作的确认、CSRF 和重复提交状态；
5. 本清单中相应的浏览器验收记录，并在 `docs/HANDOFF.md` 记录验证结果。
